
# Hotel Customers Analysis

This project analyzes hotel customer data to extract insights, clean data, and prepare it for predictive modeling.

## Project Overview

* **Data cleaning** and preprocessing of hotel customer datasets.
* **Exploratory Data Analysis (EDA)** including visualizations and statistics.
* **Reports** and **proposals** included in Word and Jupyter Notebook formats.

## Files Included

* `HotelCustomers_cleaned.csv` – Cleaned dataset.
* `Mid-Project.ipynb` – Jupyter Notebook with analysis.
* `DB.png` – Visual schema of the project database.
* `Proposal-Of-DataSet.docx` – Dataset proposal document.
* Additional files and archives for supporting data.
